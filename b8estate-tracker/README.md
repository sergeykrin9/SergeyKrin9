# B8Estate · Трекер задач

Самодостаточный трекер задач команды B8Estate — один HTML-файл без сборки и зависимостей.
Сделан по мотивам прототипа «B8Estate OS v9» (версия Алины), но переосмыслен: оставлен только
контур задач, убраны CRM / материалы / доступы.

## Как открыть

Просто открыть `index.html` в браузере — больше ничего не нужно.

## Что внутри

- **Мой кабинет** — стартовый экран (по умолчанию режим Алины): 4 цветовые колонки
  «Мои задачи / На проверку / Поставил(а) другим / Выполнено» + KPI со счётчиком просрочек.
- **Доска задач** — канбан по 6 статусам (Inbox → Готово → В работе → На проверке →
  На доработке → Выполнено) с drag&drop и фильтром по отделам.
- **Цели** — аккордеон: метрика, срок, ответственные, прогресс по подзадачам.
- **Лента активности** — журнал действий (создание, статусы, комментарии).
- **Архив** — выполненные задачи + выгрузка CSV.
- Роли: Алина (COO), Сергей (CEO/CTO), Любовь (CCO), Команда — персональный фильтр карточек.
- Подсветка дедлайнов: «просрочено N дн.», «дедлайн сегодня», «осталось N дн.».
- Поиск по задачам, хоткеи: `N` — новая задача, `Esc` — закрыть модалку.

## Данные

- Хранение — `localStorage` (ключ `b8estate_tracker_v1`).
- При первом запуске автоматически подхватываются данные из прототипов
  B8Estate OS v5–v9, если они есть в том же браузере.
- Резервное копирование и перенос между устройствами — кнопки экспорта/импорта JSON
  в шапке (⤓ / ⤒).

## Перенос в основное приложение b8estate

Файл намеренно без зависимостей: его можно положить как статическую страницу
(например, `/tasks`) или перенести логику в React-компоненты. Модель данных
(task / goal / activity) совместима с форматом прототипа v9 — экспортированный
JSON из старой версии импортируется сюда без изменений.
